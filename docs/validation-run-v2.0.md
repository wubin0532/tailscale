# v2.0 `.run` 候选验证

## 变更与来源

- 安装器版本 `2.0.0-r2`；插件界面仍为 `v2.0`。
- 上游 Tailscale `1.104.1`，源码提交 `7f4efe814ff14b064eb080344389ceb9ea2d37ac`。
- 上游源码归档 SHA-256：`bf868b2b1a46b9485d55bcda12c2d7573279ce4474bc6d607f42f1495db36ed8`。
- 使用官方构建脚本 `--box --strip`，唯一功能标签 `ts_include_cli`；未使用 `ts_omit_*`。Go `1.27.1`、CGO 关闭、UPX `5.2.1`。
- 每个包只含一份核心文件，`tailscale` 为 `tailscaled` 的相对符号链接。
- 每个架构离线携带 21 个用户态依赖包的运行文件，版本和 SHA-256 固定在 `dependencies.lock.json`。私有加载器与库不覆盖固件系统库。
- 固件框架、LuCI、fw4 和内核 TUN 支持作为安装前检查的固件基础，不宣称安装器包含跨内核通用模块。

## 已完成的本地验证

- 原有 56 项后端测试与 18 项前端测试通过。
- 新增 13 项安装器测试通过：完整载荷校验、损坏载荷拒绝、独立目录解压、已有/符号链接目标拒绝、未知选项拒绝；模拟固件升级保留配置/身份/手动防火墙、启动失败恢复、旧 IPK 删除失败恢复文件与包元数据、失败升级恢复旧开机启动链接、缺少固件框架/空间不足/锁冲突/路径越界时停止安装。
- 四种架构的载荷内容、文件权限、UID/GID、配置 0600、相对符号链接、ELF 架构、依赖清单与 SHA-256 校验通过。
- 四种核心通过 UPX 自检和解压可逆性验证；解压文件的 Go 元数据确认完整功能构建标签、固定 Go 版本和 CGO 关闭。
- 当前候选包体积约：ARM64 11.0 MB、ARMv7 10.1 MB、MIPSLE 10.2 MB、x86-64 13.1 MB。包含全部用户态依赖，不承诺旧精简核心的 6–7 MB 体积。

## 真机与发布边界

- 本轮真机测试目标由用户改为 **Home x86-64**，不安装到 Office/ARM64。
- 用户随后明确要求自行真机测试、直接打包上传；因此不安装到任何路由器，不将旧 ARM64 IPK 测试当作本轮实测。
- Linux/QEMU 的四架构命令及用户态依赖执行验证由 GitHub Actions 完成，属于执行验证，不等同其它三架构的真机验证。
- 按用户后续明确授权，构建与执行验证通过后直接替换现有 v2.0 Release 交付资产；Home 的安装、服务恢复、身份、LuCI/RPC、节点与网络实测由用户完成，结果尚未确认。
- 既有 v2.0 标签保持不动；新构建的实际源码提交写入包内 `build.json`，与旧 v2.0 标签的源码归档区别明确。
- 旧 `tailscale-luci` IPK 支持自动迁移。已有 `tailscale-luci` APK 的自动迁移尚未实现，安装器明确拒绝并保留现状。

安装器建立 root 私有恢复备份后才替换文件。安装完成仅验证本地进程与 LocalAPI；控制连接可能延迟恢复，需单独检查。UPX 用于节约磁盘空间，不据此推断实际 RSS 或 PSS 下降。
