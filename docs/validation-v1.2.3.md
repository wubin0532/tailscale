# v1.2.3 验证记录

发布包：`tailscale-luci 1.102.2-10`（Tailscale 核心版本保持 1.102.2）。

## 自动回归

- 37 项 Python 测试：配置参数边界、CLI 失败与错误脱敏、IPv4/IPv6 网段与冲突、启动等待、配置迁移、启停提交与回滚、注销返回值、防火墙规则所有权和失败恢复、后台重新应用及启动取消清理。
- 8 项 JavaScript 测试：节点 Ping、启停结果、登录失败和窗口重新打开、网段与出口输入校验、防火墙默认值、空 NAT 限制列表。
- 网段重叠检查包括 120 组随机 IPv4/IPv6 地址对，并与 Python `ipaddress` 对照。
- 四种架构安装包检查权限、root 属主、依赖和版本化视图链接。

## 真机范围

在 JDCloud RE-SS-01（aarch64_cortex-a53、LibWrt SNAPSHOT、opkg、fw4）验证安装升级、服务启停及开机启动设置、后台路由保护进程、保存并应用名称、出口网段错误提示、NAT 列表写入和清空、节点 Ping、原登录节点身份与插件未管理偏好的保留、家庭内网及外网访问。

安装前在路由器 root 私有目录备份配置、登录状态、插件文件及旧包，并解包比对配置和状态文件。测试结束恢复原名称和空 NAT 列表。

## 验证边界

- 真机仅验证 ARM64/opkg；其余架构及 APK 为构建和回归验证。
- 注销失败、登录参数和控制服务器切换的错误处理使用隔离测试；未执行真机注销、卸载、完整 Headscale 或扫码重新授权流程。
- 未在控制台批准与办公室 LAN 冲突的路由。冲突检测通过隔离场景和真机上的地址解析器验证，后台复查存在检查间隔。
- 测试网络使用透明代理和 Fake-IP，曾出现控制连接启动延迟。插件会分别显示进程和控制连接状态，控制恢复后重新应用配置；不会更改其它代理插件配置。NAT 限制不是访问控制授权。
